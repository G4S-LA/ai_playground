# Агент с сохраняемым контекстом

Решение задания вторника второй недели. Агент хранит чаты и сообщения в SQLite,
восстанавливает выбранную историю после перезапуска и продолжает диалог с тем же
контекстом. Доступны консольный и локальный веб-интерфейсы.

## Как устроено хранение

В `chat_history.sqlite3` создаются две таблицы:

```text
chats:    id, title, created_at, updated_at
messages: id, chat_id, role, content, created_at
```

`chat_id` связывает каждое сообщение с конкретным чатом. Новый чат без сообщений
называется «Пустой чат». После успешного ответа первый запрос автоматически
становится названием чата.

При открытии чата `SimpleAgent` загружает его сообщения из SQLite и добавляет их
в `messages`, отправляемые модели. После успешного ответа новая пара
`user/assistant` сохраняется одной транзакцией. Поэтому новый экземпляр агента
получает тот же контекст даже после завершения Python-процесса.

## Файлы

- `chat_repository.py` — схема SQLite и операции с чатами и сообщениями;
- `agent.py` — LLM-агент, загрузка и сохранение контекста;
- `cli.py` — выбор чата и консольный интерфейс;
- `web.py` — JSON API локального Flask-сервера;
- `templates/index.html` и каталог `static` — веб-интерфейс со списком чатов;
- `test_chat_repository.py`, `test_agent.py`, `test_web.py` — проверка базы,
  перезапуска и веб-маршрутов.

## Установка

Все команды выполняются из каталога `Week_2/tue`.

### Linux и macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

### Windows PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env`, заполните API-ключ и загрузите настройки.

Linux и macOS:

```bash
set -a
source .env
set +a
```

## Запуск CLI

```bash
python cli.py
```

При первом запуске программа создаст новый чат. При следующих запусках появится
список сохранённых чатов. Доступные команды:

- `/chats` — показать список и переключиться на другой чат;
- `/new` — создать и открыть новый чат;
- `/delete` — полностью удалить текущий чат вместе с историей;
- `/reset` — совместимый псевдоним для `/delete`;
- `/exit` — завершить программу, сохранив историю.

Меню отдельно показывает сохранённые чаты и доступные действия. Пустой новый
чат считается черновиком: если выйти или переключиться, ничего не написав, он
удаляется из SQLite и при следующем запуске не появляется в списке.

## Запуск веб-интерфейса

```bash
python web.py
```

После запуска откройте:

```text
http://127.0.0.1:5000
```

Список чатов находится слева. Кнопка «+ Новый чат» создаёт чат с названием
«Пустой чат». Можно переключаться между чатами и полностью удалять выбранный
чат. Если сохранённых чатов нет, веб-интерфейс автоматически создаёт новый.
Интерфейс читает те же таблицы SQLite, что и CLI: созданные в консоли чаты
появятся в браузере и наоборот.

При создании нового чата текущий пустой черновик удаляется. После перезапуска
веб-сервера также очищаются оставшиеся пустые черновики; чаты с сообщениями при
этом сохраняются.

После перезапуска `web.py` список и сообщения загружаются из
`chat_history.sqlite3`. Сам Flask-сервер доступен только локально на
`127.0.0.1`; наружу уходят лишь запросы агента к настроенному LLM API.

## Практическая проверка перезапуска

1. Запустите `python cli.py`.
2. Скажите: `Моё кодовое слово — маяк. Запомни его.`
3. Завершите программу командой `/exit`.
4. Снова запустите `python cli.py` и выберите сохранённый чат.
5. Спросите: `Какое у меня кодовое слово?`

При повторном открытии программа также напечатает `Восстановлено сообщений: 2`.
В запрос к LLM попадут предыдущие реплики, поэтому агент сможет ответить
`маяк`, как если бы приложение не выключалось.

## Проверка без API-ключа

```bash
python -m unittest -v
```

Тесты создают первую версию агента, сохраняют диалог во временную SQLite-базу,
создают новый экземпляр агента и проверяют, что следующий API-запрос содержит
все сообщения до перезапуска. Отдельно проверяются создание, список, открытие и
полное удаление чатов через веб-API.

Файл рабочей базы и временные SQLite-файлы добавлены в `.gitignore` и не попадут
в репозиторий.

## Переменные окружения

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `LLM_API_KEY` | Ключ API | также читается `DASHSCOPE_API_KEY` |
| `LLM_API_URL` | Полный URL Chat Completions | OpenAI `/v1/chat/completions` |
| `LLM_MODEL` | ID модели | `gpt-4o-mini` |
| `LLM_SYSTEM_PROMPT` | Инструкция агенту | краткий полезный ассистент |
| `LLM_TEMPERATURE` | Вариативность ответа от 0 до 2 | `0.7` |
| `LLM_TIMEOUT_SECONDS` | Таймаут HTTP-запроса | `120` |
| `LLM_HISTORY_DB` | Путь к SQLite-файлу | рядом с `agent.py` |
| `WEB_PORT` | Порт локального веб-сервера | `5000` |
