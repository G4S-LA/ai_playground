# Персонализированный агент с моделью памяти

Задание вторника третьей недели. Kotlin-агент расширяет три слоя памяти из
понедельника пользовательскими профилями. Доступны CLI и адаптивный
веб-интерфейс на Ktor.

## Профили пользователей

Каждый профиль содержит явно разделённые предпочтения:

- `style` — тон и подробность ответа;
- `format` — желаемая структура и оформление;
- `constraints` — ограничения, которые нужно учитывать.

Профили хранятся отдельно в `data/profiles/<profile-id>.json` и не удаляются
вместе с диалогом. Сессия хранит идентификатор активного профиля. Новый диалог,
созданный из интерфейса, наследует текущий профиль; профиль можно переключить в
любой момент. Встроенный нейтральный профиль создаётся при первом запуске.

Перед каждым обращением к модели `PromptBuilder` автоматически добавляет профиль:

```text
system instruction
[USER_PROFILE] name + style + format + constraints
[LONG_TERM_MEMORY] profile facts / decisions / knowledge
[WORKING_MEMORY] goal / context / constraints / notes
short-term dialogue
current user query
```

Предпочтения профиля применяются к подаче каждого ответа, но не отменяют
системные правила безопасности и явные требования текущего запроса. Тесты
проверяют разные profile-блоки и разные ответы на одинаковый запрос для двух
профилей.

## Модель памяти

| Хранилище | Что содержит | Область жизни |
|---|---|---|
| Краткосрочная память | текущий диалог и явные заметки | один диалог |
| Рабочая память | цель, контекст, ограничения и заметки задачи | один диалог/задача |
| Долговременная память | факты профиля, решения и знания | все диалоги |
| Профиль пользователя | стиль, формат и ограничения ответа | все диалоги выбранного пользователя |

Обычная реплика сохраняется только в краткосрочной памяти. Записи в три слоя
памяти по-прежнему создаются явно. Профиль также создаётся и редактируется явно,
а после выбора подключается к запросам автоматически.

## Запуск

Нужна JDK 17+. Из `Week_3/tue`:

```bash
./gradlew test
./gradlew run --args="cli --demo"
./gradlew run --args="web --demo"
```

В Windows PowerShell используйте `.\gradlew.bat`. Веб доступен по адресу
<http://127.0.0.1:8080>.

Для реальной OpenAI-совместимой модели скопируйте `.env.example` в `.env` и
заполните ключ. Кавычки вокруг значений необязательны:

```dotenv
LLM_API_KEY=...
LLM_MODEL=gpt-4o-mini
```

Поддерживаются `LLM_API_KEY` и `DASHSCOPE_API_KEY`. Переменные процесса имеют
приоритет над `.env`. Gradle 9.7.1 официально запускается на JDK 17–26; Java 27
пока находится вне его матрицы совместимости.

## CLI

```text
/profile show
/profile list
/profile use <profile-id>
/profile create <имя> | <стиль> | <формат> | <ограничения через ;>
/profile update <имя> | <стиль> | <формат> | <ограничения через ;>
/profile delete <profile-id>
```

Также доступны команды памяти и диалогов: `/remember`, `/memory`, `/forget`,
`/new`, `/sessions`, `/use`, `/delete`, `/help`, `/exit`.

В веб-версии редактор активного профиля находится справа над слоями памяти.
Подсчёта токенов, копирования диалога и настроек стратегии контекста нет.
