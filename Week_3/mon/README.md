# Агент с явной моделью памяти

Задание понедельника третьей недели. Реализация написана на Kotlin и доступна
в двух интерфейсах: CLI и адаптивном веб-интерфейсе на Ktor.

## Модель памяти

| Слой | Что хранит | Область жизни | Файл |
|---|---|---|---|
| Краткосрочная | текущий диалог и явные заметки диалога | один диалог | `data/short-term/<session-id>.json` |
| Рабочая | цель, контекст, ограничения и заметки текущей задачи | один диалог/задача | `data/working/<session-id>.json` |
| Долговременная | профиль, принятые решения и знания | все диалоги | `data/long-term/memories.json` |

Обычная реплика сохраняется **только в краткосрочной памяти**. Рабочая и
долговременная память не обновляются автоматически: пользователь явно выбирает
слой, категорию и текст через `/remember` в CLI или форму справа в вебе.
Явную заметку можно добавить и в краткосрочный слой.

Перед вызовом модели `PromptBuilder` собирает контекст в фиксированном порядке:

```text
system instruction
[LONG_TERM_MEMORY] profile / decisions / knowledge
[WORKING_MEMORY] goal / context / constraints / notes
short-term dialogue
current user query
```

Записи памяти помечены как данные, а не команды. При удалении диалога удаляются
его краткосрочная и рабочая память; долговременная память остаётся.

## Запуск

Нужна JDK 17+. Проект не требует конкретно JDK 21: сборка использует текущую
JDK и выпускает совместимый с Java 17 байткод. Из `Week_3/mon`:

```bash
./gradlew test
./gradlew run --args="cli --demo"
./gradlew run --args="web --demo"
```

Gradle 9.7.1 официально запускается на JDK 17–26. Java 27 пока не входит в его
матрицу совместимости; если wrapper не запускается или ведёт себя нестабильно,
укажите в `JAVA_HOME` установленную JDK 17–26.

Демо-режим не обращается к внешней модели. Веб будет доступен по адресу
<http://127.0.0.1:8080>.

Для реальной OpenAI-совместимой модели скопируйте `.env.example` в `.env`,
заполните ключ и запустите без `--demo`. Кавычки вокруг значений необязательны:

```bash
cp .env.example .env
# LLM_API_KEY=...
# LLM_MODEL=gpt-4o-mini
./gradlew run --args="web"
```

Поддерживаются `LLM_API_KEY` и `DASHSCOPE_API_KEY`, адрес API задаётся через
`LLM_API_URL`. Папку хранения можно изменить переменной `MEMORY_DATA_DIR`.
Переменные процесса имеют приоритет над одноимёнными значениями из `.env`.

## CLI-команды

```text
/remember short_term dialogue_note <текст>
/remember working <goal|context|constraint|note> <текст>
/remember long_term <profile|decision|knowledge> <текст>
/memory [all|short_term|working|long_term]
/forget <layer> <memory-id>
/new
/sessions
/use <session-id>
/delete
/help
/exit
```

В веб-версии слева остаётся список диалогов, по центру чат, справа — три
наблюдаемых слоя памяти и форма явной записи. Подсчёта токенов, копирования
диалогов и настроек стратегии контекста в этом задании нет.
