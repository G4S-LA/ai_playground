# Локальный чат на Kotlin

Kotlin/Ktor-приложение подключается к локальной Ollama, предоставляет Web UI и
HTTP API, а диалоги и сообщения сохраняет между перезапусками. Компьютер с
приложением выступает домашним сервером; чат доступен другим устройствам в той
же Wi-Fi-сети.

```text
телефон / другой компьютер
        │  HTTP :8080 + API-ключ
        ▼
Kotlin + Ktor ── хранилище диалогов
        │
        ▼
Ollama (127.0.0.1:11434)
```

## Возможности

- знакомый Web UI со списком диалогов;
- создание, переключение и удаление диалогов;
- автоматический заголовок по первой реплике;
- сохранение всей истории после перезапуска;
- передача истории текущего диалога модели;
- доступ из домашней сети;
- защита API с помощью Bearer-ключа;
- автоматический выбор установленной Ollama-модели.

Приложение не задаёт температуру, размер контекста или длину ответа: Ollama
использует стандартные параметры выбранной модели.

## Требования

- JDK 17 или новее;
- Ollama с хотя бы одной установленной chat-моделью.

Посмотреть модели:

```bash
ollama list
```

Если список пуст, загрузите подходящую модель, например:

```bash
ollama pull qwen3:8b
```

## Запуск

Все команды выполняются из `Week_6/fri`.

Один раз создайте `.env` со случайным API-ключом:

```bash
./gradlew run --args=init
```

Запустите сервер:

```bash
./gradlew run
```

На Windows:

```powershell
.\gradlew.bat run --args=init
.\gradlew.bat run
```

Откройте <http://127.0.0.1:8080> и вставьте в форму `SERVICE_API_KEY` из
`.env`. Остановить сервер можно сочетанием `Ctrl+C` в его терминале.

Если Windows-консоль некорректно показывает русский текст:

```powershell
chcp 65001
.\gradlew.bat run --args=init
```

## Выбор модели

По умолчанию `OLLAMA_MODEL` в `.env` пустой. Сервис получает список из Ollama и
автоматически использует первую доступную модель. Чтобы предпочесть конкретную,
скопируйте её точное имя из `ollama list`:

```dotenv
OLLAMA_MODEL=llama3.2:3b
```

Если указанной модели нет, сервис не останется в состоянии «не готова», а
возьмёт первую из фактически установленных моделей.

После изменения `.env` перезапустите приложение. Проверить Ollama и фактически
выбранную модель можно командой:

```bash
./gradlew run --args=check
```

## Доступ с другого устройства

Оба устройства должны находиться в одной обычной Wi-Fi-сети. Узнайте адрес
компьютера-сервера:

```bash
# macOS
ipconfig getifaddr en0

# Linux
hostname -I
```

Если адрес сервера `192.168.1.114`, откройте на телефоне или ноутбуке:

```text
http://192.168.1.114:8080
```

Быстрая проверка без API-ключа:

```text
http://192.168.1.114:8080/health
```

Если страница не открывается, разрешите Java входящие подключения в firewall и
проверьте, что используется не гостевая сеть с изоляцией клиентов.

## HTTP API

```text
GET    /health
GET    /api/chats
POST   /api/chats                 {}
GET    /api/chats/{id}
DELETE /api/chats/{id}
POST   /api/chats/{id}/messages   {"message":"Привет!"}
```

Для всех `/api/*` маршрутов нужен заголовок:

```text
Authorization: Bearer <SERVICE_API_KEY>
```

Пример создания диалога:

```bash
set -a
source .env
set +a

curl http://127.0.0.1:8080/api/chats \
  -X POST \
  -H "Authorization: Bearer $SERVICE_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{}'
```

## Автотесты

Тесты не требуют Ollama. Они проверяют конфигурацию, генерацию `.env`,
сохранение и удаление диалогов, передачу истории fake-модели, авторизацию,
HTTP API и наличие прежних элементов Web UI:

```bash
./gradlew test
```

## Настройки

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `SERVICE_HOST` | `0.0.0.0` | сетевой интерфейс сервиса |
| `SERVICE_PORT` | `8080` | порт Web UI и API |
| `SERVICE_API_KEY` | — | обязательный приватный ключ |
| `OLLAMA_URL` | `http://127.0.0.1:11434` | адрес локальной Ollama |
| `OLLAMA_MODEL` | пусто | автовыбор или точное имя модели |
| `CHAT_DATABASE` | `data/local-chat.db` | файл с историей диалогов |
| `OLLAMA_TIMEOUT_SECONDS` | `300` | таймаут ответа модели |

Для доступа через интернет не открывайте порт `8080` напрямую на роутере:
обычный HTTP не шифрует API-ключ. Используйте приватную VPN-сеть.
