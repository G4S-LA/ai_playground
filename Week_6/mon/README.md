# Локальная LLM: Ollama + CLI + Web + SQLite

Задание понедельника шестой недели. Приложение обращается к Ollama только по
локальному адресу, поддерживает одноразовый и интерактивный CLI, предоставляет
Web UI и HTTP API, а все диалоги сохраняет в SQLite.

## Что проверяет задание

| Требование | Реализация |
|---|---|
| модель запускается локально | Ollama на `http://127.0.0.1:11434` |
| доступ через CLI или HTTP API | команды `check`, `ask`, `cli` и Web API приложения |
| простой запрос получает ответ | `./gradlew run --args=check` отправляет вопрос `2 + 2` |
| новые диалоги можно добавлять и удалять | кнопки в Web UI и команды `/new`, `/delete` в CLI |
| диалоги переживают перезапуск | таблицы `chats` и `messages` в `data/local-chat.db` |

> `nomic-embed-text`, использованная в задании прошлого понедельника, строит
> эмбеддинги, но не генерирует ответы. Для чата нужна generative-модель. По
> умолчанию проект использует `qwen2.5:3b`; через `OLLAMA_MODEL` можно указать
> любую другую установленную chat-модель.

## Подготовка Ollama

Нужны JDK 17+ и Ollama. Если Ollama уже установлена, достаточно запустить
приложение или сервер и один раз загрузить chat-модель:

```bash
ollama serve
ollama pull qwen2.5:3b
```

На macOS приложение Ollama обычно само поднимает локальный сервер, поэтому
отдельная команда `ollama serve` может не понадобиться.

Прямая проверка Ollama через её CLI:

```bash
ollama run qwen2.5:3b "Ответь одним числом: сколько будет 2 + 2?"
```

Прямая проверка локального HTTP API:

```bash
curl http://127.0.0.1:11434/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen2.5:3b","stream":false,"messages":[{"role":"user","content":"Ответь одним числом: сколько будет 2 + 2?"}]}'
```

## Быстрая проверка проекта

Все команды выполняются из `Week_6/mon`:

```bash
./gradlew run --args=check
```

Команда проверит, что локальный HTTP API Ollama доступен, выбранная модель есть
в `/api/tags`, а `/api/chat` возвращает содержательный ответ на простой вопрос.
Она печатает три строки `OK` и фактический ответ модели.

Один запрос из CLI:

```bash
./gradlew run --args="ask Назови столицу Франции одним словом"
```

Интерактивный CLI с сохранением истории:

```bash
./gradlew run --args=cli
```

Доступные команды:

```text
/new          создать новый диалог
/chats        показать сохранённые диалоги и их ID
/use <id>     открыть сохранённый диалог
/delete       удалить текущий диалог и его сообщения
/help         показать команды
/exit         выйти; история останется в SQLite
```

## Web UI

```bash
./gradlew run --args=web
```

Откройте <http://127.0.0.1:8080>. Слева отображаются сохранённые диалоги и
состояние Ollama. Кнопка «Новый диалог» создаёт отдельную историю, а «Удалить»
каскадно удаляет её сообщения из SQLite. Заголовок нового диалога формируется
из первой реплики. После перезапуска приложения список и вся история
восстанавливаются из `data/local-chat.db`.

Web-интерфейс использует HTTP API приложения:

```text
GET    /api/info
GET    /api/chats
POST   /api/chats
GET    /api/chats/{id}
DELETE /api/chats/{id}
POST   /api/chats/{id}/messages   {"message":"Привет!"}
```

Запрос к Ollama отправляется только после `POST .../messages`. В него входят
системная инструкция, сохранённая история выбранного диалога и новая реплика.
Пара `user/assistant` записывается в SQLite одной транзакцией только после
успешного ответа модели.

## Настройки

Настройки читаются сначала из `Week_6/mon/.env`, затем из переменных процесса;
переменные процесса имеют приоритет. Пример находится в `.env.example`.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `OLLAMA_URL` | `http://127.0.0.1:11434` | локальный сервер Ollama |
| `OLLAMA_MODEL` | `qwen2.5:3b` | установленная chat-модель |
| `OLLAMA_SYSTEM_PROMPT` | краткий русский промпт | системная инструкция |
| `OLLAMA_TEMPERATURE` | `0.7` | вариативность ответа, `0..2` |
| `OLLAMA_TIMEOUT_SECONDS` | `120` | таймаут генерации |
| `CHAT_DATABASE` | `data/local-chat.db` | файл SQLite |
| `WEB_HOST` | `127.0.0.1` | локальный интерфейс сервера |
| `WEB_PORT` | `8080` | порт Web UI |

Если уже установлена другая модель, загрузка Qwen не нужна:

```bash
OLLAMA_MODEL=llama3.2:3b ./gradlew run --args=check
```

## Автотесты

```bash
./gradlew test
```

Тесты не требуют Ollama: fake-модель проверяет передачу контекста, Web API и
ответы, а временная SQLite-база — создание, восстановление после нового
экземпляра приложения и каскадное удаление диалогов.
