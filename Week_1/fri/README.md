# Сравнение слабой, средней и сильной моделей

Скрипт отправляет один и тот же запрос трём моделям через OpenAI-compatible
Chat Completions API и сравнивает:

- содержание и качество ответов;
- время получения полного ответа;
- входные, выходные и общие токены;
- расчётную стоимость, если указаны тарифы моделей.

Конкретные модели скрипт не выбирает. Их идентификаторы задаются переменными
`LLM_MODEL_WEAK`, `LLM_MODEL_MEDIUM` и `LLM_MODEL_STRONG`.

## Меню

При запуске доступны следующие действия:

1. выполнить запрос только на слабой модели;
2. выполнить запрос только на средней модели;
3. выполнить запрос только на сильной модели;
4. сравнить все три модели;
0. выйти.

В пункте 4 три основных запроса стартуют параллельно. Они получают одинаковые
системное сообщение, пользовательский запрос и `temperature`; отличается только
поле `model`. Ответы печатаются в порядке «слабая — средняя — сильная», независимо
от порядка их завершения.

После трёх ответов сильная модель получает отдельный запрос: она анонимно
оценивает качество ответов A, B и C, сопоставляет его с измеренными метриками и
формирует короткий вывод. Это четвёртый служебный API-вызов. Его время, токены и
стоимость показываются отдельно и не включаются в сравнение трёх моделей.

Автоматическая оценка качества субъективна и не является точным бенчмарком. Для
более надёжного результата стоит повторить эксперимент на нескольких задачах и
проверить вывод вручную.

## Метрики

Время измеряется от начала HTTP-запроса до получения полного ответа. Количество
токенов читается из объекта `usage` ответа API. Такой объект входит в формат
[Chat Completions](https://developers.openai.com/api/reference/cli/resources/chat/subresources/completions),
но конкретный совместимый провайдер может вернуть неполные данные.

Расчётная стоимость определяется отдельно для входных и выходных токенов:

```text
стоимость = входные токены × цена входа / 1 000 000
            + выходные токены × цена выхода / 1 000 000
```

Цены необязательны. Если оставить их пустыми, скрипт всё равно покажет время и
токены, а стоимость отметит как неизвестную. Тарифы необходимо брать у своего
провайдера: они могут зависеть от региона, длины контекста, кэширования, thinking
mode и действующих скидок. Например, Alibaba публикует актуальные ставки на
странице [Model Studio pricing](https://www.alibabacloud.com/help/en/model-studio/model-pricing).

Под ресурсоёмкостью в этом задании понимаются потраченные токены и расчётная
стоимость. Реальную загрузку GPU и объём памяти внешний API обычно не сообщает.

## Установка

Все команды выполняются из каталога `Week_1/fri`.

### Linux и macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

### Windows PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Настройка

Скопируйте `.env.example` в `.env` и укажите API и три model ID:

```dotenv
LLM_API_KEY=your-api-key
LLM_API_URL=https://api.openai.com/v1/chat/completions

LLM_MODEL_WEAK=your-weak-model-id
LLM_MODEL_MEDIUM=your-medium-model-id
LLM_MODEL_STRONG=your-strong-model-id
```

Для Alibaba Model Studio вместо `LLM_API_KEY` также можно использовать
`DASHSCOPE_API_KEY`. URL должен соответствовать workspace и региону ключа.

Если модели платные, дополнительно укажите цены за миллион токенов:

```dotenv
LLM_WEAK_INPUT_PRICE_PER_MILLION=0.1
LLM_WEAK_OUTPUT_PRICE_PER_MILLION=0.4
LLM_MEDIUM_INPUT_PRICE_PER_MILLION=0.5
LLM_MEDIUM_OUTPUT_PRICE_PER_MILLION=1.5
LLM_STRONG_INPUT_PRICE_PER_MILLION=2.0
LLM_STRONG_OUTPUT_PRICE_PER_MILLION=8.0
LLM_PRICE_CURRENCY=USD
```

Числа выше приведены только как пример формата, а не как реальные тарифы.

Для загрузки `.env` в текущий терминал:

```bash
set -a
source .env
set +a
```

## Запуск

Интерактивный режим:

```bash
python llm.py
```

Запрос можно передать аргументом, но меню выбора модели всё равно появится:

```bash
python llm.py "Объясни алгоритм Дейкстры и оцени его сложность"
```

После выполнения меню появляется снова. Нажатие Enter вместо нового запроса
повторяет предыдущий. Во время ожидания можно ввести `0` и нажать Enter, чтобы
отменить текущий одиночный запрос или все три параллельных запроса.

## Переменные окружения

| Переменная | Назначение | Обязательна |
|---|---|---|
| `LLM_API_KEY` | API-ключ | да; альтернатива — `DASHSCOPE_API_KEY` |
| `LLM_API_URL` | Полный URL Chat Completions | нет |
| `LLM_MODEL_WEAK` | Model ID слабой модели | да |
| `LLM_MODEL_MEDIUM` | Model ID средней модели | да |
| `LLM_MODEL_STRONG` | Model ID сильной модели и оценщика | да |
| `LLM_*_INPUT_PRICE_PER_MILLION` | Цена миллиона входных токенов | нет |
| `LLM_*_OUTPUT_PRICE_PER_MILLION` | Цена миллиона выходных токенов | нет |
| `LLM_PRICE_CURRENCY` | Обозначение валюты | нет, `USD` |
| `LLM_SYSTEM_PROMPT` | Общая системная инструкция | нет |
| `LLM_TEMPERATURE` | Общая температура | нет, `0.2` |
| `LLM_TIMEOUT_SECONDS` | Таймаут одного вызова | нет, `360` |

Скрипт не включает и не отключает thinking mode и не задаёт `response_format`.
Каждая модель использует поведение своего провайдера по умолчанию.
