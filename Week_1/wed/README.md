# Сравнение способов решения задачи через LLM API

Скрипт решает одну логическую, алгоритмическую или аналитическую задачу через
OpenAI-compatible Chat Completions API четырьмя способами:

1. отправляет задачу без дополнительных инструкций;
2. добавляет инструкцию `Решай пошагово.`;
3. сначала просит модель составить промпт, затем отправляет сгенерированный
   промпт той же модели для решения;
4. создаёт в промпте группу из аналитика, инженера и критика и получает решение
   от каждого эксперта.

В меню также есть пункт 5, который последовательно запускает все четыре способа
для одной задачи. При этом выполняется пять API-вызовов: по одному для способов
1, 2 и 4 и два для способа 3.

Во всех запросах сохраняются одна модель и одна температура. Каждый способ
запускается независимо: ответы и история предыдущего способа модели не
передаются. `response_format` и ограничения длины намеренно не используются,
чтобы сравнение показывало влияние именно разных промптов.

На каждый отдельный API-вызов установлен таймаут 360 секунд. В способе 3 это
отдельные шесть минут на генерацию промпта и отдельные шесть минут на решение.

## Установка

Все команды выполняются из каталога `Week_1/wed`.

### Linux и macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

### Windows PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Настройка API

Для OpenAI задайте переменные вручную или скопируйте `.env.example` в `.env`:

```bash
export LLM_API_KEY="your-api-key"
export LLM_API_URL="https://api.openai.com/v1/chat/completions"
export LLM_MODEL="gpt-4o-mini"
```

Для DeepSeek или Qwen через Alibaba Model Studio используйте
`.env.model-studio.example`. Замените `YOUR_WORKSPACE_ID` на идентификатор
workspace и убедитесь, что API key относится к тому же workspace и региону.

Для загрузки `.env` в Bash:

```bash
set -a
source .env
set +a
```

## Запуск

Интерактивный режим:

```bash
python llm.py
```

Задачу можно передать аргументом, но меню выбора способа всё равно появится:

```bash
python llm.py "Есть 8 монет, одна тяжелее остальных. Найдите её за два взвешивания"
```

После выполнения снова появляется меню. Нажатие Enter вместо новой задачи
повторяет предыдущую задачу. Для полного выполнения задания выберите пункт 5.

Во время ожидания любого ответа можно ввести `0` и нажать Enter. Текущий
HTTP-запрос будет отменён, а скрипт вернётся в меню. Если отменить один из
способов при автоматическом сравнении, оставшиеся способы не запускаются.

## Что именно отправляется

### 1. Прямой ответ

В `user`-сообщение передаётся исходная задача без добавленного текста.

### 2. Пошаговое решение

К исходной задаче добавляется только инструкция:

```text
Решай пошагово.
```

Такая инструкция просит модель показать явную последовательность решения. В
[официальной документации OpenAI](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-4.1)
это описывается как prompting-induced planning: результат и полезность инструкции
нужно оценивать экспериментально для выбранной модели и задачи.

### 3. Промпт, созданный моделью

Первый API-вызов получает роль специалиста по проектированию промптов и должен
вернуть только готовый промпт, не решая задачу. Скрипт показывает этот текст, а
затем передаёт его в `user`-сообщении второго API-вызова. Второй вызов не получает
ответ или историю первого вызова.

### 4. Группа экспертов

В одном промпте задаются три роли:

- аналитик формализует условие и предлагает решение;
- инженер ищет практический или алгоритмический способ и проверяет вычисления;
- критик независимо решает задачу, ищет ошибки и граничные случаи.

Модель должна вывести отдельное решение каждой роли и общий итог группы. Это
ролевая симуляция в одном вызове API, а не три независимо запущенные модели.

Скрипт не включает и не отключает thinking mode. Каждый API-вызов использует
поведение выбранной модели и провайдера по умолчанию.

## Переменные окружения

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `LLM_API_KEY` | Ключ API | также читается `DASHSCOPE_API_KEY` |
| `LLM_API_URL` | Полный URL Chat Completions | OpenAI |
| `LLM_MODEL` | Имя модели | `gpt-4o-mini` |
| `LLM_SYSTEM_PROMPT` | Общая системная инструкция | `Ты — полезный ассистент.` |
| `LLM_TEMPERATURE` | Температура всех вызовов | `0.2` |
| `LLM_TIMEOUT_SECONDS` | Таймаут одного API-вызова в секундах | `360` |
