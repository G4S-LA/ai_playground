# Сравнение ответов при разной температуре

Скрипт отправляет пользовательский запрос в модель через OpenAI-compatible
Chat Completions API. Перед каждым запросом меню предлагает выбрать одно из
трёх значений `temperature`:

- `0` — наиболее сфокусированный и стабильный ответ;
- `0.7` — умеренная вариативность;
- `1.2` — повышенная вариативность.

В API-запросе меняется только `temperature`. Модель, системный промпт и
пользовательский запрос остаются теми же. `top_p`, thinking mode, ограничения
длины и `response_format` скрипт не задаёт.

Согласно [официальной документации OpenAI](https://developers.openai.com/api/reference/cli/resources/chat/subresources/completions/methods/create),
`temperature` принимает значения от 0 до 2. Чем выше значение, тем более
случайным может быть ответ; чем ниже — тем более сфокусированным. Температура
`0` повышает стабильность, но не гарантирует побайтово одинаковые ответы.

## Установка

Все команды выполняются из каталога `Week_1/thu`.

### Linux и macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

### Windows PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Настройка API

Задайте настройки API переменными окружения:

```bash
export LLM_API_KEY="your-api-key"
export LLM_API_URL="https://api.openai.com/v1/chat/completions"
export LLM_MODEL="gpt-4o-mini"
```

Также можно скопировать `.env.example` в `.env`, заполнить его и загрузить
переменные в текущий терминал:

```bash
set -a
source .env
set +a
```

Для совместимого провайдера укажите его полный URL и имя модели. Вместо
`LLM_API_KEY` можно использовать `DASHSCOPE_API_KEY`.

## Запуск

Интерактивный режим:

```bash
python llm.py
```

Запрос можно передать аргументом, но меню выбора температуры всё равно
появится:

```bash
python llm.py "Придумай три названия для приложения заметок"
```

После ответа меню появится снова. Чтобы проверить тот же запрос при другой
температуре, выберите новое значение и нажмите Enter вместо ввода запроса —
скрипт повторит предыдущий текст. Для выхода выберите пункт `0`.

Поддержка параметра `temperature` зависит от выбранной модели и провайдера. Если
модель его не поддерживает, API вернёт ошибку, которую скрипт покажет в консоли.

## Переменные окружения

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `LLM_API_KEY` | Ключ API | также читается `DASHSCOPE_API_KEY` |
| `LLM_API_URL` | Полный URL Chat Completions | OpenAI |
| `LLM_MODEL` | Имя модели | `gpt-4o-mini` |
| `LLM_SYSTEM_PROMPT` | Системная инструкция | краткий полезный ассистент |
